# Agent Note: 基于 skill 的股票分析 Agents

Status: proposed

[English](2026-10-01-skill-backed-stock-agents.md) | 中文

## 问题

这个 fork 已有股票工具和自选股，但用户还没有可重复使用的研究任务入口。现有 `stock-analysis` preset 已提供股票工具与 skill 加载，而从标准 preset 继承的 coding agent 人设和工具不符合专注研究的产品定位。具名 Agents 的目录需要可找回的分析记录、可见的数据来源和时间，以及低成本新增专题的方式。

## 提案

侧边栏设置一个 **Agents** 入口，主区域展示由开发者维护的卡片。首批三个专题是 A 股智能选股、热点分析和大盘分析。每个专题的任务说明与卡片资料放在同一份 DSH `SKILL.md` 中。首版一次性建设通用目录、启动、transcript（文本记录）和历史界面；此后新增专题应只需增加有效的 skill 定义。其他被发现的 skill 不进入此目录。

输入型卡片先展示查询输入框和样例。智能选股接受行情、技术、财务、行业和概念条件的自然语言组合，候选集合必须来自 `iwencai_astock_selector`。无需查询的卡片在打开时新建记录并立即流式回答。每次运行产生独立 Session；追问留在对应 Agent 记录中，重新分析前可编辑原查询，提交后产生新 Session。Agents 拥有独立入口、目录、历史列表和结果页；选择记录后仍停留在 Agents。普通 Conversation 只展示自由对话。两边复用同一套对话渲染和 Session 持久化。目录在 Agents 自己的历史列表中展示最近记录。

卡片明确调用对应 skill。专题记录的每次追问都采用最新可用的 skill 定义。既有回答保持历史原貌。skill 被删除或改名后，旧记录仍可阅读，但专题追问需等原标识恢复或完成迁移。专题记录中的无关问题引导用户进入普通 Conversation。

结果复用现有流式对话和 Markdown 呈现。关键结论标明数据时间和来源；核心数据缺失时不生成报告，次要数据缺失时标记受影响的结论。休市期间的行情采用最近有数据的交易日并写明日期，更新的资讯保留各自时间。智能选股不设产品层候选数量上限或主观推荐排名：若供应商提供总数，则显示总数，并标明页码、截断情况和后续页，按需继续读取。热点分析用资讯与行情依据说明主题，不宣称统一热度分数。大盘分析覆盖主要 A 股指数、成交、涨跌分布和板块表现，并可按用户要求关注某个指数。

面向股票的 Chat 和专题运行专注证券研究及行情分析，不采集客户资料，不提供个性化买卖或仓位建议。首期平台工作调整 `stock-analysis` preset 继承的 coding agent 人设和工具范围。各专题的 skill 指导工具选择，不设逐专题强制工具白名单。

## 曾考虑的替代方案

- **每个专题一个运行时 agent 或 preset：**否决。专题行为是对既有股票能力的任务说明；分别组合会重复配置并拖慢新增速度。
- **卡片只发送自然语言而不明确调用 skill：**否决。description 匹配由模型决定，不能保证卡片运行其具名专题。
- **每个专题长期共用一条 Session：**否决。不同筛选条件与重新运行会混合依据和追问。
- **固定只展示十只股票或由模型给出推荐排名：**否决。筛选接口支持分页，而产品定位是研究辅助，不是个性化选股建议。

## 验收标准

- 侧边栏打开一个 Agents 目录，仅展示三个标记为股票专题的卡片；加入第四份有效 `SKILL.md` 不需要编写专题专属应用代码。
- 输入型与无需查询的卡片均能正确启动；每次新运行形成独立、持久的 Session，在 Agents 内流式呈现回答，并能从 Agents 历史重新打开。
- Conversation 历史不展示 Agent 记录，并保留普通对话空状态；打开 Agent 记录后仍停留在 Agents 页面。两边复用同一套 Conversation 渲染与 Session 持久化。
- 卡片首轮及每次专题追问都加载指定 skill；修改 skill 会影响旧记录后续轮次而不改写已有回答。skill 缺失时记录仍可读，并明确阻止专题追问。
- 智能选股使用 `iwencai_astock_selector` 获取候选集合，说明分页与不完整结果，筛选失败时不编造候选股。热点和大盘结果标明时间窗口与依据日期。
- 核心数据失败、部分数据失败、休市和离题追问均呈现约定结果。无密钥 Session 快照覆盖三个专题的输出及用户可见的失败路径。

## 风险

- 早先的 skill 说明仍保留在 Session 历史中。后续轮次采用新版时，必须让当前说明优先生效，同时不篡改既有回答；测试需覆盖真实修改 skill 后恢复旧 Session 的情形。
- 当前股票 preset 复制标准 preset，包括 coding agent 能力，且股票工具目录较大。专注研究的组合调整必须维持有意义的防漂移检查并测量请求开销。
- 供应商的总数、时间戳、链接和列并不一致。报告必须区分缺失的元数据与完整依据，不能把单页结果写成全部命中结果。
